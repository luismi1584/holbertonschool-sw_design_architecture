# Introduction to UML Modeling

This directory contains UML modeling exercises for the
Holberton School Software Design and Architecture project.

## Task 0 - Class Diagram

File: 0-class_diagram.mmd

A Mermaid UML class diagram representing a Library Loan System.

The diagram models:
- Library
- Book
- User
- Loan

It includes class attributes, methods, relationships,
and multiplicities.
